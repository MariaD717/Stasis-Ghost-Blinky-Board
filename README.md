# Ghost-Blinky-Board
I am making a blinky board shaped like a ghost, following the starter project guide. This is my first PCB project ever. It is also my second ever hardware project. A lot of my files are named "Phoenix..." because I was originally going to make it the shape of a phoenix, but all the images were too complicated.

# Why?
I am making this project because it is fun. Since I find hardware interesting, I decided this was a good way to learn about it.
